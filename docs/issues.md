## Dependency interpretation

Audits are dated advisory lookups, not a claim that the dependency graph is current or safe.
I15 triage, 2026-10-25. Reachability decided which advisories mattered; all in-range fixes were
applied regardless, and `package.json` floors were raised for Hono (`^4.13.11`) and Vite (`^8.1.6`).

| Path | Advisory packages | Reachable? |
|---|---|---|
| API runtime (behind nginx `/api/`) | Hono query parser/routing, Zod via better-auth request validation | Yes, so patched. `parseBody()` is used only by `/fs/xml` and `/fs/cdr`, which authenticate first and are not proxied by nginx. CORS, language, `serveStatic`, `toSSG`, proxy and JSX helpers are unused. |
| Portal browser bundle | Seroval (TanStack router), Zod (better-auth client) | Bundled, so patched. The SPA never deserializes server-rendered Seroval payloads. |
| Portal build/dev | Vite, brace-expansion, nanoid, PostCSS parsers, source-map-js | Build or loopback dev server only. Patched. |

Accepted residuals (rerun with each audit; [raw](reviews/dependencies-2026-10-25-patched.json)):

- **API: esbuild ≤ 0.24.2** via `drizzle-kit > @esbuild-kit/core-utils` (pins `~0.18.20`). The
  advisory is esbuild's dev *server* answering cross-origin requests; drizzle-kit only transforms
  `drizzle.config.ts` at deploy and never starts it. Clears when drizzle-kit drops `@esbuild-kit`.
- **Site: Astro ≤ 7.3.1 (critical), sharp, esbuild.** Fixed only in Astro 7 (major). The site is
  `output: "static"` with no adapter and no image optimisation, built from repository content; the
  deployed Worker (`site/worker.ts`) has no imports. The XSS, path-boundary and AVIF advisories need
  untrusted input at render or request time, which this build does not have. Upgrade to Astro 7 as
  its own change.
- **Site: undici < 7.30.1** via `wrangler > miniflare` (exact pin). Used by local `wrangler dev`
  and deploy tooling, never shipped to the Worker.
